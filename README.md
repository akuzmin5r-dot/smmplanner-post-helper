# SMMplanner Helper

Два независимых пользовательских скрипта. Устанавливайте один подходящий вариант в каждом браузере.

| Устройство | Страница SMMplanner | Установка |
| --- | --- | --- |
| Компьютер · Tampermonkey | /home/posts — старая версия | [Установить скрипт](https://raw.githubusercontent.com/akuzmin5r-dot/smmplanner-post-helper/main/smmplanner-tampermonkey.user.js) |
| iPhone · Userscripts для Safari | /home/new_posts/, /home/post_v3 — новая версия | [Открыть скрипт](https://raw.githubusercontent.com/akuzmin5r-dot/smmplanner-post-helper/main/smmplanner-mobile.user.js) |

## Компьютер

Установите Tampermonkey, откройте ссылку из таблицы и подтвердите установку. Если открывается только код, создайте новый скрипт в Tampermonkey, замените весь шаблон этим кодом и сохраните. Разрешите выполнение пользовательских скриптов, если браузер запрашивает это. Обновите /home/posts.

## iPhone

Установите приложение Userscripts, выберите в нём папку для скриптов и включите расширение в настройках Safari. Разрешите ему доступ к smmplanner.com. Откройте ссылку из таблицы в Safari и используйте установку через расширение Userscripts. Если доступен только код, сохраните файл с окончанием .user.js в выбранную папку. Обновите страницу SMMplanner.

## Возможности

- Автовыбор выбранных страниц ВК и ОК для нового поста. Проверьте страницы в настройках «Плагин»: настройки хранятся в этом браузере, отдельно для каждой команды.
- Вставка текста с сохранением абзацев; та же кнопка очищает заполненное поле.
- Удаление узнаваемой подписи о подписке в конце вставленного текста. Подпись можно вернуть до следующего изменения текста.
- Название видео из первого абзаца без эмодзи, без открытия видеоредактора. Ручное название сохраняется. Функция отключается в настройках.
- Копирование первой строки поста и всех доступных опубликованных ссылок: пустая строка после заголовка, ссылки на отдельных строках без пустых строк между ними.
- Настольные карточки группируются по новости; оформление можно отключить в настройках.

Автовыбор и автоматическое название видео не меняют существующие публикации. Отправка, планирование и сохранение постов выполняются штатными кнопками SMMplanner по вашему нажатию. Получение ссылок использует только чтение данных сайта.

## Обновления

Стабильные ссылки updateURL и downloadURL находятся в начале обоих файлов. Tampermonkey может проверять обновления по ним. На iPhone доступность автоматической проверки зависит от установленной версии Userscripts; при необходимости установите обновлённый файл по той же ссылке.

Отключите прежние копии помощника и старое отдельное расширение, чтобы они не выполнялись одновременно. ZIP-сборки и старые установочные варианты больше не поддерживаются.

Скрипты не содержат логинов, паролей, идентификаторов выбранных страниц или аналитики. Они работают внутри авторизованной страницы; настройки сохраняются локально. При изменении интерфейса или внутренних моделей SMMplanner может потребоваться адаптация.

## Проверки кода

Без установки зависимостей, Node.js 22 или новее:

```sh
node --check smmplanner-tampermonkey.user.js
node --check smmplanner-mobile.user.js
node --test tests/*.test.cjs
```

Автоматические проверки не заменяют проверку в настоящем Safari на iPhone.
