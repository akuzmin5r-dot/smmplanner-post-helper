# SMMplanner Helper

Помощник для старой страницы https://smmplanner.com/home/posts.

## Установка

[Установить для Tampermonkey](https://raw.githubusercontent.com/akuzmin5r-dot/smmplanner-post-helper/main/smmplanner-tampermonkey.user.js). Можно также создать новый скрипт, вставить содержимое файла и сохранить. Отключите предыдущие версии помощника и отдельное расширение.

[Открыть Safari-скрипт для установки](https://raw.githubusercontent.com/akuzmin5r-dot/smmplanner-post-helper/main/smmplanner-safari.user.js). iPhone: установите Userscripts, включите его расширение в Safari, разрешите smmplanner.com. Откройте ссылку на Safari-скрипт в Safari, затем меню расширения Userscripts и подтвердите установку, если оно предлагает её. При ручной установке добавьте файл в каталог Userscripts. Откройте меню Userscripts и обновите страницу.

## Автовыбор — первоначальная настройка

1. Нажмите небольшую кнопку «Автовыбор» в правом нижнем углу, над виджетом чата.
2. Откроется пустая форма нового поста и список доступных страниц.
3. Выберите нужные ВК и ОК, нажмите «Сохранить и выбрать».
4. Сохраняется только настройка помощника в localStorage браузера. Пост не сохраняется и не публикуется.
5. Закройте пустую форму без сохранения. В дальнейшем выбранные страницы добавляются автоматически при создании поста.
6. На каждом устройстве и для каждой команды выбор настраивается отдельно. Его можно отключить в окне настройки.
7. После автоматического выбора можно убрать страницу вручную — помощник не добавит её повторно.
8. При редактировании существующего поста помощник не меняет список страниц.
9. Если одноимённые страницы отображаются несколько раз, выберите нужный вариант по порядку в списке SMMplanner. При изменении количества совпадений требуется повторная настройка.

## Копирование

Нажмите «Копировать ссылки» в строке опубликованного поста. Помощник откроет его окно, прочитает полный текст и все ссылки из блоков «Опубликован», затем закроет окно кнопкой отмены.

Формат: первая непустая строка текста, пустая строка, все доступные опубликованные ссылки на соседних строках. Порядок — как в окне поста; одинаковые адреса исключаются. Если одна сеть ещё публикует пост, копируются только уже доступные ссылки. Если ссылок нет, буфер не меняется.

Если браузер не разрешает автоматическое копирование, появляется окно с готовым текстом и кнопкой «Скопировать». При необходимости текст можно выделить вручную.

## Данные и ограничения

В исходном коде нет настроек конкретного аккаунта, имён сообществ, идентификаторов команд, авторских контактов, паролей, cookies или токенов. Данные страниц и пользовательский выбор остаются в текущем браузере. Аналитики, сторонних запросов и внешних зависимостей нет.

Для сбора ссылок помощник открывает, читает и закрывает окно поста; при автовыборе добавляет выбранные страницы в новую форму. Он не публикует, не сохраняет и не удаляет посты автоматически. Верхний дубликат кнопки ОК вызывает штатное действие SMMplanner только по нажатию пользователя и сохраняет выбранные страницы, дату, время и проверки формы.

Старая версия SMMplanner может менять разметку — в таком случае требуется обновление. Версия Safari использует изолированный контекст Userscripts и не требует доступа к внутреннему JavaScript сайта. Реальная работа на конкретном iPhone должна быть проверена после установки.

## Обновления

В скриптах заданы постоянные @updateURL и @downloadURL. Возможность и частота проверки обновлений зависят от менеджера скриптов. В Userscripts обновление может потребовать ручной проверки через меню расширения. Не используйте старые персонализированные файлы для публичной загрузки.

## Проверка кода

Требуется Node.js: node report.test.cjs. Тесты проверяют заголовок, произвольное число ссылок, переносы строк, дубликаты, небезопасные URL и отсутствие данных.

## Интерфейс 2.1.0

Настройки вынесены в небольшую плавающую кнопку в углу и не меняют расположение кнопок создания поста и истории. На сенсорных экранах кнопки помощника учитывают текущий масштаб компьютерной версии страницы. У копирования есть статус загрузки и подтверждение результата; технический индикатор внизу убран после загрузки интерфейса.

В новом посте над полем текста расположена кнопка «Вставить текст». Она добавляет текст из буфера в конец поста, сохраняя уже набранное. Safari может запросить системное разрешение на вставку. При отказе показывается подсказка; автоматического обхода разрешения нет. В окне редактирования опубликованного поста кнопка не добавляется.

## Отдельное расширение для компьютера

В репозитории есть папка extension. Откройте chrome://extensions или browser://extensions, включите режим разработчика, выберите «Загрузить распакованное расширение» и укажите эту папку. Не включайте одновременно расширение и Tampermonkey-версию. Расширение запрашивает разрешения чтения и записи буфера для кнопок вставки и копирования.

## Интерфейс 2.2.0

Кнопка автовыбора находится в углу над чатом. Верхний блок постинга остаётся без элементов помощника. Копирование — светлая кнопка с иконкой внизу карточки, без полосы на всю ширину. Кнопка вставки текста компактно расположена над полем нового поста. Для сенсорного экрана размер области нажатия учитывает масштаб страницы. Предыдущие настройки автовыбора сохраняются.

## Редактор 2.3.0

В новом посте сверху две равные колонки: «Вставить текст» и «Опубликовать пост». Вторая кнопка повторяет штатную ОК: действие зависит от выбранных даты и времени и может запланировать пост. Если штатная ОК заблокирована, дубликат тоже заблокирован. Внизу штатные ОК и Отмена занимают по половине ширины.

«Фото/видео» и «Опрос» увеличены и расположены в равных колонках. Прочие инструменты и редкие параметры находятся под «Дополнительные настройки». Скрытие не изменяет их значения; на кнопке отмечается число включённых параметров.

Размеры рассчитываются по ширине макета и экрану, без пересчёта при pinch zoom. На экране кнопки естественно приближаются вместе со страницей, но их размеры в CSS и пропорции колонок не прыгают.

Обновлённое оформление старой страницы включено по умолчанию и отключается в настройках автовыбора. Оно меняет цвета, границы, скругления и состояния элементов, не перестраивая колонки страницы. Компоновка редактора включается только при наличии ожидаемых штатных элементов. При существенном изменении сайта может потребоваться обновление помощника.

Проверки дубликата действия выполняются только на тестовых объектах. На реальном аккаунте кнопки ОК и публикации при проверке не нажимаются.
