# Новый редактор: iPhone и компьютер

Единый скрипт для новой версии SMMplanner на iPhone и компьютере. Старая версия `/home/posts` использует прежний плагин.

[Открыть скрипт для установки](https://raw.githubusercontent.com/akuzmin5r-dot/smmplanner-post-helper/main/smmplanner-mobile.user.js)

В Safari откройте ссылку, затем меню расширения Userscripts → установите скрипт. Разрешите Userscripts работу на smmplanner.com и обновите страницу. Прежний скрипт SMMplanner в Userscripts на телефоне отключите, чтобы его оформление не пересекалось с новым.

На компьютере установите тот же скрипт через Tampermonkey. Альтернатива без Tampermonkey — отдельное расширение из папки `new-editor-extension`: загрузите её как распакованное расширение в Chrome или Яндекс Браузере. Используйте один вариант нового помощника, чтобы не дублировать его. Старое расширение можно оставить для `/home/posts`.

Скрипт работает на `/home/new_posts/` и `/home/post_v3`. На главной сохраняется стандартный интерфейс: вместо звёздочки появляется копирование опубликованных ссылок и на телефоне, и на компьютере.

На компьютере обычное нажатие «Создать пост» именно в `/home/new_posts/feed` открывает `/home/post_v3`, сохраняя параметры текущего адреса. Переход загружает страницу заново. «История», календарь и редактирование существующих публикаций не перехватываются: в них штатный переход может передавать дополнительные параметры.

В форме:

- «Вставить текст» меняется на «Очистить текст». Вставка кнопкой не переводит фокус в поле.
- Между абзацами отображается одна пустая строка; одиночные переносы внутри абзаца сохраняются. Под заголовком формы есть небольшой отступ для рамки фокуса.
- В версии 1.1.1 подсказка и введённый текст имеют одинаковые 16 px / 24 px и совпадающую начальную точку внутри поля.
- Подписная строка в конце вставленного текста удаляется. Действие можно отменить.
- Chat GPT+ вынесен из поля, лишняя панель инструментов скрыта. Штатный ластик сохранён.
- Область загрузки и превью вложений остаются штатными. После них идут время и выбранные страницы, затем элементы и настройки поста.
- Кнопки публикации и планирования находятся рядом, черновик — ниже.
- Страницы выбираются из сохранённых настроек. Совместимый выбор старого скрипта переносится локально; при неоднозначности нужно выбрать страницы в разделе «Плагин». Ручное снятие страницы сохраняется до закрытия формы.
- Название нового видео берётся из первого абзаца без эмодзи. Открывать редактор видео не требуется. Непустое ручное название не заменяется.

Настройки находятся внизу формы, в разделе «Плагин». Автовыбор, очистку подписи и название видео можно выключить независимо.

Копирование формирует первую строку поста, пустую строку и опубликованные ссылки по одной на строку. Данные читаются из SMMplanner с текущей авторизацией. Скрипт не отправляет текст или ссылки сторонним сервисам. При недоступности буфера появляется поле для ручного копирования.

Выбор страниц хранится только в браузере. В публичном коде нет названий сообществ, их идентификаторов, логинов, паролей или токенов. Скрипт сам не нажимает публикацию, планирование или сохранение черновика.

Совместимость зависит от структуры и внутреннего состояния нового редактора. Если SMMplanner изменит их, автоматизация может потребовать обновления. Штатные кнопки отправки не подменяются.

Проверено на настоящей странице в настольном Chromium и с мобильным viewport, touch и iPhone user agent. Проверка на физическом iPhone/Safari требуется отдельно; эмуляция не заменяет её. Финальная отправка поста в рамках проверки не выполнялась.

Проверки текста: `node --test mobile.test.cjs`.
