Установка в Chrome и Яндекс Браузер

Версия 3.1.0 для старой страницы /home/posts.
Для iPhone и нового редактора используется отдельный smmplanner-mobile.user.js.

Распакуйте архив в постоянную папку.
Chrome: откройте chrome://extensions
Яндекс Браузер: откройте browser://extensions
Включите режим разработчика, нажмите «Загрузить распакованное расширение», выберите папку с manifest.json.
Отключите старое расширение и версию Tampermonkey, если они установлены.
Обновите https://smmplanner.com/home/posts.
Откройте «Плагин» под основной кнопкой планирования и один раз выберите страницы ВК и ОК. При выключенном оформлении настройки доступны через «Автовыбор» справа внизу.
Настройка хранится только в этом браузере. Автоматически помощник посты не публикует и не сохраняет. Кнопка «Опубликовать пост» запускает штатную ОК только по вашему нажатию, с выбранными датой и временем.
Разрешения на буфер нужны для кнопок копирования и вставки текста.
При обновлении замените файлы, нажмите обновление у расширения и перезагрузите страницу.
